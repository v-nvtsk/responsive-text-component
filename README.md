# React Responsive Text

Это React-компонент, который динамически изменяет отображаемый текст в зависимости от доступной ширины контейнера. Он получает массив текстовых строк и отображает самую длинную из них, которая помещается в контейнер, не переносясь на новую строку.

Это решение идеально подходит для адаптивных интерфейсов, где нужно показывать разные варианты текста в зависимости от размера элемента — например, полное название на большом экране и сокращенное на мобильном.

## Ключевые особенности

- **Адаптивность:** Автоматически подбирает лучший вариант текста при изменении размера контейнера.
- **Производительность:** Использует `ResizeObserver` для эффективного отслеживания изменений размеров, минимизируя нагрузку на производительность. Логика вынесена в хук `useResponsiveText`.
- **Эффективное использование `ResizeObserver`:** Все экземпляры компонента используют один-единственный (синглтон) экземпляр `ResizeObserver`. Это реализовано через `resizeObserverManager`, который управляет подписками и отписками, что позволяет избежать создания множества наблюдателей и значительно экономит ресурсы.
- **Простота использования:** Компонент имеет простой и понятный API.

## Как использовать

Поскольку этот компонент не опубликован как npm-пакет, необходимо скопировать директорию `src/components/ResponsiveText` в ваш проект.

### Пример использования

Импортируйте компонент и передайте ему массив текстовых вариантов в свойстве `items`. Вам не нужно заранее сортировать массив — компонент сам измерит реальную ширину каждого варианта с учётом шрифтов и стилей, после чего выберет самый длинный из тех, что помещаются в контейнер.

```jsx
import { ResponsiveText } from "./components/ResponsiveText";
import { getNumberVariants } from "./utils/get-number-variants"; // Пример утилиты для генерации вариантов

export function MyComponent() {
  // Пример с разными форматами числа
  const numberItems = getNumberVariants(987654321); // ["987 654 321", "987,6 млн", "987 млн", "1 млрд"]

  // Пример с произвольными строками
  const textItems = [
    "Показать все детали подробно",
    "Показать все детали",
    "Все детали",
    "Детали",
  ];

  return (
    <div style={{
      margin: "0 auto",
      maxWidth: "300px",
      border: "1px solid #ccc",
      padding: "10px" }}>
      {/* Этот компонент покажет "987,6 млн" или другой подходящий вариант */}
      <ResponsiveText items={numberItems} align="left" />

      {/* Этот компонент покажет "Показать все детали" или более короткий вариант */}
      <ResponsiveText items={textItems} align="center" style={{ marginTop: "20px" }} />
    </div>
  );

}
```

## API компонента

| Проп | Тип | Описание | По умолчанию |
| :--- | :--- | :--- | :--- |
| `items` | `string[]` | **(Обязательный)** Массив текстовых строк для отображения. Компонент выберет самый длинный вариант, который помещается в контейнер. | `[]` |
| `align` | `'left' \| 'center' \| 'right'` | Горизонтальное выравнивание текста внутри контейнера. | `'left'` |

Компонент также принимает все стандартные атрибуты элемента `<div>`, такие как `className`, `style` и т.д.

## Локальная разработка

Для запуска демонстрационного проекта локально выполните следующие шаги:

1.  **Клонируйте репозиторий:**
    ```bash
    git clone https://github.com/v-nvtsk/responsive-text-component.git
    cd responsive-text-component
    ```

2.  **Установите зависимости:**
    ```bash
    npm install
    ```

3.  **Запустите dev-сервер:**
    ```bash
    npm run dev
    ```
    Проект будет доступен по адресу `http://localhost:5173` (или другому, указанному в консоли).

## Скрипты

-   `npm run dev`: запуск сервера для разработки.
-   `npm run build`: сборка проекта для продакшена.
-   `npm run lint`: проверка кода с помощью ESLint.
-   `npm run preview`: запуск локального сервера для просмотра собранного проекта.
